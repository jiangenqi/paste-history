# UI 设计规范 - PasteHistory（历史粘贴板）

## 设计理念

简约、直观、优雅。参考 Apple 设计语言（macOS / iOS），强调留白、圆角和柔和阴影。
不追求复杂装饰，让内容本身成为视觉焦点。

> v3.0.0 起主色调从淡蓝改为 Apple 蓝（`#007AFF`），本文档以实际实现为准。

---

## 色彩方案

所有颜色通过 `renderer/style.css` 的 `:root` CSS 变量定义，组件样式必须引用变量。

### CSS 变量一览（与实现一致）

| 变量 | 值 | 说明 |
|------|------|------|
| `--primary` | `#007AFF` | 主色：按钮、链接、高亮、选中态 |
| `--primary-hover` | `#0062CC` | Primary hover 态 |
| `--bg-light` | `#F2F2F7` | 主窗口背景 |
| `--bg-pinned` | `rgba(0,0,0,0.025)` | 置顶卡片背景 |
| `--text-primary` | `#1D1D1F` | 标题、正文 |
| `--text-secondary` | `#86868B` | 时间戳、辅助信息 |
| `--text-placeholder` | `#B0B0B8` | placeholder 文字 |
| `--card-bg` | `rgba(255,255,255,0.85)` | 卡片背景 |
| `--card-border` | `rgba(0,0,0,0.04)` | 卡片边框 |
| `--separator` | `rgba(0,0,0,0.06)` | 分隔线 |
| `--danger` | `#E53E30` | 删除、危险操作 |
| `--success` | `#2FA84F` | 成功提示 |

### 阴影

| 变量 | 值 |
|------|------|
| `--shadow-card` | `0 1px 2px rgba(0,0,0,0.04), 0 0 0 1px rgba(0,0,0,0.02)` |
| `--shadow-card-hover` | `0 2px 8px rgba(0,0,0,0.06), 0 0 0 1px rgba(0,0,0,0.03)` |
| `--shadow-window` | `0 4px 24px rgba(0,0,0,0.1)` |

## 窗口尺寸

- **主窗口**: 400×560px，最小 320×400px，可调整大小
- **位置**: 首次启动屏幕中央，之后记住上次位置（`window-bounds.json`）
- **任务栏**: 主窗口保留在任务栏（`skipTaskbar: false`），点击窗口外不消失；
  关闭按钮 = 隐藏，最小化按钮 = 最小化
- **眼睛窗口**: 66×72 / 84×100 / 120×126（小/中/大），置顶、不抢焦点
- **伴生窗口**: 110×70，透明、忽略鼠标事件
- **详情窗口**: 500×400，最小 300×200，普通系统边框

## 背景与质感

窗口背景使用纯色 `#F2F2F7`，卡片使用半透明白叠加细描边模拟层次。
（早期设计稿的 Windows acrylic 毛玻璃方案未采用，保证跨版本渲染一致。）

## 组件设计

### 搜索栏

```
┌──────────────────────────────────────┐
│  🔍  搜索历史...                      │
└──────────────────────────────────────┘
```
- 高度: 36px；圆角: `--radius-md`
- 聚焦时: 边框变为 Primary 色

### 文字卡片

- 内容超出 2 行截断；操作按钮（📌 ⭐ 🗑）默认隐藏，hover 时显示
- 置顶卡片：背景 `--bg-pinned`，左侧 `3px solid rgba(0,0,0,0.08)` 细条标识

### 图片卡片

- 缩略图：最大高度 120px，保持比例
- 显示图片编号（#N）；右键查看原图（详情窗口）

### 文件卡片

- 每个文件一行：18×18 Windows 系统图标 + 文件名
- 最多显示 3 行，超出显示"…等 N 个文件"；图标缺失时回退 📁 emoji

### 分类标签（收藏夹视图）

- 标签栏："全部" + 用户分类 + `+`/`−` 按钮
- 卡片底部分类标签：每个分类一个 tag，点击弹出多选分类下拉（`.picker-check` 复选框）

### 设置面板

- 分组卡片（`.setting-group`）：通用 / 快捷操作 / 眼睛模式 / 数据 / 危险操作
- 行布局 `.setting-row`（label 左、控件右）+ `.setting-row-stacked`（纵向）
- 分段控件 `.option-btn`：浅灰底，选中态蓝底蓝字（iOS 分段控件风格）
- 开关 `.toggle-switch`：0.25s cubic-bezier 过渡
- 操作行 `.setting-row-action`：蓝色/红色文字 + `›` 箭头，hover 微移

### Toast 提示

- 复制成功/分类创建等轻提示：底部居中淡入淡出（`.copy-toast`），约 1.2s 后消失

## 交互动效

| 场景 | 动效 | 时长 |
|------|------|------|
| 窗口打开 | 淡入 + 轻微放大 (scale 0.95→1) | 150ms |
| 窗口关闭 | 淡出 | 100ms |
| 新卡片出现 | 从上方滑入 | 200ms |
| 悬停操作按钮 | 淡入显示 | 100ms |
| 搜索过滤 | 即时，无动画 | 0ms |
| 点击卡片反馈 | 卡片背景闪一下主色淡色 | 200ms |
