# 需求文档 - PasteHistory（历史粘贴板）

## 产品概述

一款运行在 Windows 上的轻量级桌面应用，在后台自动记录用户复制到剪贴板的内容
（文字、图片、文件），用户可以随时通过全局快捷键呼出窗口查看、搜索、置顶、收藏、
分类、删除历史记录，并设置保留期限与最大记录数自动清理过期内容。
所有数据仅保存在本地。

> 本文档描述 v3.0.0 的实际功能范围。

## 目标用户

Windows 电脑用户，需要频繁复制粘贴内容（文字工作者、设计师、开发者等）。

---

## 功能需求

### F1 - 自动记录剪贴板
- **优先级**: P0（核心功能）
- **描述**: 应用在后台运行时，自动检测剪贴板变化，记录新复制的内容
- **支持类型**:
  - 纯文本（UTF-8）
  - 图片（保存为 PNG）
  - 文件（资源管理器中复制的文件/文件夹，通过 Windows CF_HDROP 格式检测）
- **去重**: 连续复制完全相同的内容，只保留一条记录
- **记录数量**: 受"最大记录数"设置限制（默认 200，可选 500/1000/自定义 50–10000），
  超出时自动删除最旧的未置顶未收藏记录

### F2 - 历史记录查看
- **优先级**: P0
- **描述**: 通过全局快捷键呼出主窗口，以卡片形式展示历史记录
- **排序**: 置顶优先，其余按复制时间降序排列（最新的在最上面）
- **卡片内容**:
  - 文字类：显示文字内容预览（超出长度截断）
  - 图片类：显示缩略图与图片编号
  - 文件类：显示系统图标 + 文件名（最多 3 行，超出显示"…等 N 个文件"）
  - 每条记录显示相对时间（如"2分钟前"、"昨天 14:30"）
- **点击行为**: 点击卡片将内容重新复制到剪贴板，窗口保持打开，显示 toast 提示

### F3 - 搜索功能
- **优先级**: P1
- **描述**: 在主窗口顶部提供搜索输入框
- **搜索范围**: 文字内容、图片编号/尺寸、文件路径
- **搜索方式**: 实时过滤，模糊匹配，不区分大小写；`%`/`_` 按字面量匹配
- **交互**: 输入即搜索，无需按回车（150ms 防抖）

### F4 - 置顶功能
- **优先级**: P1
- **描述**: 用户可以将重要的记录固定到列表顶部
- **交互**: 鼠标悬停卡片时显示置顶按钮（📌图标）
- **行为**:
  - 置顶的卡片始终显示在列表最上方（在非置顶卡片之前）
  - 置顶的卡片不受自动清理策略影响，永不过期
  - 已置顶的卡片可以取消置顶

### F5 - 删除功能
- **优先级**: P1
- **描述**: 用户手动删除不需要的历史记录
- **交互**: 鼠标悬停卡片时显示删除按钮（🗑️图标）
- **行为**:
  - 点击后直接删除（无需确认弹窗，保持简洁）
  - 文字/文件类记录：软删除，定期物理清除
  - 图片类记录：软删除 + 同步删除本地图片文件（防止磁盘泄漏）

### F6 - 保留期限设置
- **优先级**: P1
- **描述**: 用户可设置历史记录的自动清理策略
- **选项**: 1 天 / 3 天 / 5 天 / 自定义天数（1–365）
- **清理规则**:
  - 非置顶且超过保留期限的记录自动删除（图片同步删除文件）
  - 每次应用启动时执行一次清理检查
  - 每隔 1 小时执行一次清理检查
  - 软删除记录同步物理清除

### F7 - 全局快捷键
- **优先级**: P2
- **描述**: 通过系统级快捷键呼出/隐藏主窗口
- **默认快捷键**: `Alt + V`
- **行为**: 窗口隐藏时呼出并聚焦，窗口可见时最小化
- **可自定义**: 在设置页面录制修改，立即生效

### F8 - 系统托盘
- **优先级**: P2
- **描述**: 在 Windows 任务栏右下角显示应用图标
- **右键菜单**: 打开 PasteHistory / 设置 / 退出
- **双击图标**: 呼出主窗口

### F9 - 开机自启
- **优先级**: P2
- **描述**: 应用可随 Windows 系统启动自动运行
- **默认**: 开启
- **启动行为**: 开机自启时不弹出主窗口，驻留系统托盘

### F10 - 收藏与多分类
- **优先级**: P1
- **描述**: 收藏夹视图 + 多分类管理
- **收藏**: ⭐ 收藏任意类型记录；收藏夹视图只显示已收藏记录
- **分类**: 一条收藏可同时属于多个分类；分类标签栏支持新建/重命名/删除/过滤；
  删除分类不删除收藏；旧数据自动迁移到关联表

### F11 - 文件记录操作
- **优先级**: P1
- **描述**: 文件类记录的复制与文件系统联动
- 点击卡片：将文件复制回剪贴板（可粘贴到资源管理器/聊天窗口）
- 右键菜单：打开文件 / 在文件夹中显示 / 查看详情

### F12 - 详情窗口
- **优先级**: P2
- **描述**: 右键文字/图片/文件记录，在新窗口查看完整内容

### F13 - 导出历史
- **优先级**: P2
- **描述**: 将全部记录导出为排版整齐的文本文件
- **内容**: 类型统计、置顶/收藏统计、每条记录的分类归属与精确时间，
  CJK 宽字符对齐排版

### F14 - 眼睛模式
- **优先级**: P3（趣味功能）
- **描述**: 桌面出现一只跟随鼠标的眼睛；鼠标静止超过设定时长（默认 120 秒）
  逐渐犯困入睡；支持拖拽移动位置，单击关闭

### F15 - 桌面固定
- **优先级**: P2
- **描述**: 底部工具栏"钉在桌面"开关，窗口始终置顶显示

## 非功能需求

### N1 - 性能
- 剪贴板轮询间隔: 500ms（文件检测为异步 PowerShell 调用，不阻塞轮询）
- 主窗口打开/关闭响应: < 300ms
- 历史记录列表滚动: 流畅

### N2 - 可靠性
- 应用崩溃后重启，已存储的历史数据不丢失（每次写入后立即持久化到磁盘）
- 图片保存失败不影响文字记录
- 数据库迁移与脏数据清理在启动时自动执行

### N3 - 资源占用
- 后台运行时内存占用: < 150MB（含 Chromium 运行时）
- 空闲 CPU 占用: 目标 < 5%

### N4 - 数据隐私
- 所有数据存储在本地，不上传网络（程序不包含任何网络请求逻辑）
- 图片存储在应用专属目录，路径读取前校验目录归属，防止路径遍历

### N5 - 平台
- 仅支持 Windows x64（文件剪贴板读写依赖 .NET Clipboard API 与 PowerShell）
